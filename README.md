# ColorOS 云控去除 8.1

屏蔽 ColorOS 部分云控行为。仅在 OnePlus ACE5 Pro / ColorOS 16.0.1.300 实测，其余机型、系统适配程度未知，自测。

## 核心设计

**三层拦截**：hosts 劫持 + IP 拦截 + TLS SNI 域名分流，互为兜底，不依赖单点。

**动态 IP 解析**：开机实时解析云控域名（DoH），CDN 轮换照拦，不存在静态表过期问题。

**共享 IP 精准分流**：共用 IP 不整段拦，按 SNI 只拦目标域名流量，避免误伤同 IP 上的其他服务。

**关键路径保护**：AI 功能、系统 httpdns 等用户功能路径明确排除，配置内固化说明。宁漏勿伤，若有问题请反馈至酷安用户——好想玩鸣潮。

**可审计拦截**：配套监测可记录被拦域名的解析与连接行为，拦截效果有据可查。

**卸载自净**：删除模块即恢复全部规则、解冻应用、清理数据，无残留。

## 适配性

- **Root 管理器**：KernelSU、Magisk；兼容 Magisk 模块格式的 APatch 等未实测。
