# ColorOS云控去除（二改）
屏蔽 ColorOS 云控的 KernelSU/Magisk 模块。

用酷安 xyz小智 用户的模块塞给AI进行二改，几乎90%的东西都是AI改的。仅在一台设备上进行了全面测试，自用没有问题，别人有问题那我不负责。

只屏蔽了部分云控，想要屏蔽全面需自行抓包添加入config.sh然后重跑service.sh或者重启设备。如果不好用或者有问题可随时卸载，无残留。

然后是AI对于修改config.sh的一些话：
1.改完config.sh必须重跑sh service.sh(或 KernelSU 点动作→音量+）才生效，改文件本身不自动生效；不存在的包/域名/IP自动跳过，多写无害。
2.域名有两个入口:BLOCKED_DOMAINS 是"解析成IP再断网"；另外5个地区域名还写在system/etc/hosts 里劫持0.0.0.0(锁死更彻底)。想放行某个域名，两处都要删，只删一处会漏。
3.注释里不能出现"、$、 三个符号
(config.sh头写了警告），写备注时避开。另外两个机制性提醒（给大佬交代时也用得上）：uid=1000的系统包在包列表里会被自动跳过(断不了UID，靠域名/IP层兜底);CDN 域名想彻底锁死用hosts写0.0.0.0，比只靠解析可靠。
